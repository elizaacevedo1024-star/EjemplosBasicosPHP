🧺 Primeros pasos y ejemplos en PHP
Este repositorio reúne diversos casos prácticos desarrollados en PHP ideados para comprender y afianzar los fundamentos del lenguaje, entre ellos:

*Declaración de variables y conversión de tipos (casting)
*Estructuras condicionales (if / else) y manejo de fechas
*Interacción con formularios HTML y gestión de solicitudes HTTP (GET y POST)
*Resolución de operaciones aritméticas y lógica de calculadora utilizando funciones como round
*Integración y uso de código PHP dentro de estructuras HTML

⚙️ Requisitos previos
Para poner en marcha estos ejemplos, es necesario contar con un entorno de desarrollo local configurado con soporte para PHP. Por lo general, se recomienda utilizar paquetes integrados que despliegan rápidamente un stack completo con servidor web, bases de datos y herramientas complementarias.

📌 Aclaración: Estas herramientas actúan como entornos simulados en tu equipo y no deben confundirse con servidores de producción reales.

Herramienta de desarrollo recomendada:

Visual Studio Code

## 🛠️ Cómo usar este repositorio

1. Descarga o clona el repositorio, y ubícalo en la carpeta `www` (si usas WampServer) o `htdocs` (si usas XAMPP):
```bash
   git clone https://github.com/elizaacevedo1024-star/EjemplosBasicosPHP.git
```

2. Para ejecutar los archivos, escribe en tu navegador:
   `http://127.0.0.1/practicas/` o
   `http://localhost/practicas/`
